## 特色

- 🔐 **AES-GCM 端到端加密** — PBKDF2 派生密钥 + AES-GCM 加密，主密码不存储
- 💾 **本地优先架构** — 数据只在你自己的设备上，隐私安全自主可控
- 👨‍👩‍👧 **家庭授权共享** — 设置关联人与应急接收人
- ⏱ **长期未登录触发** — 设定期限未登录自动生成应急文本包交付家人
- 📱 **三端支持** — Windows 桌面 + Android 手机 + 网页版
- 📋 **完整审计日志** — 操作全程可追溯

## 安全说明

⚠️ 网页版原型的加密依赖浏览器 Web Crypto API；正式版（电脑端/手机端）采用原生加密方案，更适合真实敏感数据保管。
